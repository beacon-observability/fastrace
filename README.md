# Fastrace

**Based on [fast/fastrace](https://github.com/fast/fastrace).**

Beacon maintains this Rust tracing library independently from a pinned upstream source baseline, without a GitHub fork relationship. Upstream source, crate names, APIs, copyright notices, and the Apache-2.0 license are retained.

The first Beacon source release is [v0.1.0](https://github.com/beacon-observability/fastrace/releases/tag/v0.1.0). Use its fixed Git tag or verified source archive; upstream crates.io packages have separate ownership and versions.
